**MINESWEEPER**



- Initiating game : 
	- Generate as many tile objects as nessecary. 
	- Randomize bomb placement
	- Calculate the # of bombs around any given tile, iterating through each
	- Make the first click safe (no guessing mode)

- Gameplay 
	- Once a tile is clicked, timer starts, measuring time in integers of seconds, rounded from miliseconds. This happens only for the first tile. 
	- If the smiley face is clicked, the initiation method is called.
	- For each flag placed down, the flag counter goes down by one.
	- If a tile has a flag, it cannot be left clicked. It can however be removed via a right click, adding 1 to the flag counter.
	- If the flag counter is at 0, no more flags can be placed. 
	- If a tile that has no adjacent mines is clicked, all tiles adjacent will be revealed, until there is an adjacent bomb.
	- Once all flags are placed, and only on bombs, go to Game End and turn the smiley face to a glasses face, _OR_ if a bomb is clicked,
	  go to Game End and turn the smiley face to a x_x sad face. 

- Game End(Seperate into *bombClicked* and *won* endings)
	- Displays a addon to the window at the side, displays time on the timer (rounded to the thousanths place from miliseconds), displays the # of clicks. 
	- bombClicked
		- Reveals all bombs that were not flagged.
		- Indicates all flags that were not placed on bombs as red.
	- won
		- Only displays the addon window.
		
		
- Eventual addons
	- Storing Personal Records of times, efficency etc
	- Solving method for more stats after a run
	- No Guessing Mode
